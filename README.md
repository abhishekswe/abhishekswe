## Projects

### [agent-fastpath](https://github.com/abhishekswe/agent-fastpath)

An MCP server that gives coding agents (Claude Code, Codex, Cursor) quick checks before they act: ship gates on CI logs, risk checks on shell commands, file triage that keeps files out of the agent's context, and browser verification. Clear-cut cases are decided by rules; the rest go to TypeSafe's Jev API, and every answer comes back as `accept`, `review`, or `escalate`.

TypeScript · MIT · [npm](https://www.npmjs.com/package/agent-fastpath) · listed on [MCP Market](https://mcpmarket.com/server/agent-fastpath) and [Glama](https://glama.ai/mcp/servers/abhishekswe/agent-fastpath) · [website](https://abhishekswe.github.io/agent-fastpath/)

### [PIE — Personal Intent Engine](https://github.com/abhishekswe/personal-intent-engine)

Side project: a macOS app where you press a hotkey, speak, and get a structured prompt at your cursor, with transcription running locally (whisper.cpp). Built while learning Rust and Tauri.

### [DevVault](https://github.com/abhishekswe/Devvault)

Local-first developer notes: TipTap block editor, IndexedDB storage, fuzzy search, GitHub sync with conflict resolution. Next.js 14 + TypeScript.
